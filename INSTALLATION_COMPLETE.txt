================================================================================
                      TROUBLESHOOTING
================================================================================

Q: Animations not showing?
A: 1. Check browser console for errors
   2. Verify classes are applied in HTML
   3. Disable browser extensions temporarily
   4. Try a different browser

Q: Animations too fast/slow?
A: Edit the duration in globals.css:
   @keyframes sidebar-slide-in {
     /* animation runs for 400ms - change this value */
   }

Q: Want to disable animations?
A: Add to element: style={{animation: 'none'}}

Q: PowerShell script won't run?
A: Right-click INSTALL.ps1 → Run with PowerShell
   Or: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
