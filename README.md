# 🚀 Etsy AI Command Center

Production-ready AI-powered Etsy automation platform with advanced animations and Claude API integration.

## ⚡ Quick Start (PowerShell)

**Recommended way** - Handles everything with animations enabled:

```powershell
# PowerShell (Windows)
.\INSTALL.ps1

# Or skip to dev mode:
.\INSTALL.ps1 -DevMode:$true
```

Or simply double-click: **RUN_APP.bat** or **INSTALL.ps1**

## Manual Start

```bash
npm install
npm run dev
```

## ✨ Features

### Core Features
- 📊 Real-time dashboard with Etsy metrics
- 🤖 8 AI agents powered by Claude
- 📦 Product listing management
- 🔐 JWT authentication
- 💰 Demo mode with sample data
- 📈 Analytics & optimization

### 🎬 Premium Animations
- ✨ **Sidebar Slide-In** (400ms) - Smooth navigation sidebar entrance
- 🎭 **Page Transitions** (400ms fade-in) - Elegant page content transitions
- ✨ **Card Glows** (3s loop) - Emerald & blue pulsing card highlights
- 🎨 **Staggered Lists** - Sequential entrance for multiple items
- ⚡ **Button Effects** - Tactile press animations
- 🌟 **Text Glows** - Important elements with pulsing highlights

## 🏗️ Tech Stack

- **Backend**: Node.js + Express + TypeScript
- **Frontend**: React + TypeScript + Tailwind CSS
- **Styling**: CSS Animations (GPU-accelerated)
- **Database**: PostgreSQL (optional)
- **AI**: Claude API (Anthropic)
- **Build**: Vite + Rollup

## 🎯 5 AI Phases

1. **Phase 1**: Trend Research & Competitor Analysis
2. **Phase 2**: Product Creator (AI-generated variations)
3. **Phase 3**: Listing Manager (SEO optimization)
4. **Phase 4**: Analytics Dashboard
5. **Phase 5**: Store Optimizer (performance tuning)
